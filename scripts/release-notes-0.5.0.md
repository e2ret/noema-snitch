## Noema Snitch 0.5.0

Раздел «Устройства» дорос до Charles — по всему, что можно увидеть без установки сертификата на телефон.

### Что нового
- **SSL / TLS, как вкладка SSL в Charles.** Из открытой части «рукопожатия» видно: имя сервера (SNI), версия TLS, шифр, протоколы ALPN (h2 / http/1.1), версии и шифры клиента, число расширений, возобновлена ли сессия. Если приложение подключается по IP, настоящее имя хоста берётся из SNI. В колонке «Путь» для HTTPS теперь видно, например, `TLSv1.3 · h2`.
- **Время по этапам:** DNS, соединение, рукопожатие TLS, первый байт, всего — с полосками в инспекторе.
- **Контроль доступа.** Прокси принимает только устройства из локальной сети; по желанию — только разрешённые («Разрешить» прямо в списке устройств, остальные получают 403).
- **Пауза записи:** трафик идёт, но не записывается.
- **Замедление сети (throttling):** EDGE, 3G, LTE, «Плохой Wi-Fi» — работает и для HTTPS.
- **Сессии:** сохранить запись в файл `.noemasession` и открыть позже; экспорт в HAR/CSV остался.
- **Через внешний прокси:** цепочка через HTTP-прокси с CONNECT, например mixed-порт mihomo/Clash (`127.0.0.1:7890`).

### Обновление
Одной командой в Терминале:

    curl -fsSL https://raw.githubusercontent.com/e2ret/noema-snitch/main/install.sh | bash

или скачайте DMG ниже. Правила и настройки сохраняются. Сетевой помощник в этой версии не менялся.
