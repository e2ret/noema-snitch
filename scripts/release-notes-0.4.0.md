## Noema Snitch 0.4.0

### Новое: раздел «Устройства» — смотрите, куда ходят приложения на iPhone и iPad
Как в Charles: Noema Snitch запускает на Mac прокси, а телефон указывает его в настройках Wi-Fi.
**На телефон ничего не ставится.**

- **Подключение:** на iPhone — Настройки → Wi-Fi → ⓘ → Настройка прокси → Вручную, сервер — адрес Mac (показан в приложении), порт `8888`.
- **Все запросы устройства:** время, приложение, хост, объём, длительность. Для обычного HTTP — полный путь и код ответа. Содержимое HTTPS остаётся зашифрованным: видно куда, кто и сколько, но не что.
- **Приложение определяется** по заголовку User-Agent, который присылает iOS (в том числе с пробелами и по-русски: «Home Assistant», «Сбер»). Для системных служб без имени — подпись по адресу: «Геолокация iOS», «Уведомления Apple», «App Store», «iCloud», а также трекеры (Firebase, AppsFlyer, Adjust, реклама Google…). Такие подписи выделены курсивом.
- **Группировка по приложениям:** какие хосты использует каждое приложение, сколько запросов и трафика.
- **Экспорт** в HAR (Chrome DevTools, Charles) и CSV (Excel, Numbers).
- Несколько устройств сразу, с именами из роутера (например, `iPhone-Eduard.lan`).

Когда закончите — выключите прокси на телефоне, иначе без запущенного Noema Snitch он останется без интернета.

### Установка и обновление
Одной командой в Терминале:

    curl -fsSL https://raw.githubusercontent.com/e2ret/noema-snitch/main/install.sh | bash

или скачайте DMG ниже. Правила и настройки сохраняются.
Сетевой помощник в этой версии не менялся — обновлять его не нужно.
